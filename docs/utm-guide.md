# UTM-метки «Уместно» — руководство для маркетинга

Единый стандарт пометки ссылок, чтобы в Яндекс.Метрике было видно, **откуда** пришёл
посетитель, **из какого материала** и **из какого конкретного поста/пина**.
Документ живой: новые площадки добавляем отдельными разделами в конце.

---

## 1. Зачем вообще метки
Без меток переходы из соцсетей и мессенджеров часто попадают в **«Прямые заходы»**
(особенно из мобильных приложений — они теряют referrer). Метка живёт прямо в ссылке,
поэтому доходит всегда и позволяет:
- видеть трафик по каждой площадке (Pinterest, ВК, Telegram…);
- сравнивать, **какая статья** и **какой конкретный пост** приводят людей и конверсии.

## 2. Из чего состоит метка (5 параметров)
К ссылке через `?` добавляются параметры, разделённые `&`:

| Параметр | Что означает | Пример |
|---|---|---|
| `utm_source` | площадка (откуда) | `Pinterest`, `vk`, `telegram` |
| `utm_medium` | тип трафика | `organic` / `social` (бесплатно), `cpc` (реклама) |
| `utm_campaign` | **что продвигаем** — тема/статья | `razdeliteli` |
| `utm_content` | **какой именно пост/креатив** | `action`, `pain`, `cover` |
| `utm_term` | ключевое слово (для рекламы) | обычно не используем |

**Золотое правило:** `campaign` = ЧТО продвигаем (статья), `content` = КАКОЙ пост/креатив.

## 3. Наши соглашения (соблюдать всем)

**Кампании по статьям** (`utm_campaign`):
| Статья | utm_campaign |
|---|---|
| Разделители для ящиков | `razdeliteli` |
| Как навести порядок в комоде | `komod_poryadok` |
| Органайзер для белья в комод | `organayzer_belya` |

Новая статья → новая короткая кампания латиницей (по смыслу slug'а).

**Правила именования значений:**
- только латиница, **нижний регистр** (исключение — `utm_source=Pinterest`, см. раздел Pinterest);
- один разделитель — **дефис** `-` (например `before-after`);
- коротко и по смыслу: `action`, `pain`, `tips`, `cover`, `stories`, `post1`.

## 4. Конструктор ссылки
Берём «чистый» адрес статьи и добавляем хвост:
```
https://umestno-home.ru/blog/<slug>/?utm_source=<площадка>&utm_medium=<тип>&utm_campaign=<статья>&utm_content=<пост>
```
Пример (пин «боль» для статьи про разделители):
```
https://umestno-home.ru/blog/razdeliteli-dlya-yashchikov/?utm_source=Pinterest&utm_medium=organic&utm_campaign=razdeliteli&utm_content=pain
```
Удобно собирать через «Компоновщик URL» (Google Campaign URL Builder) — но проще копировать наши готовые шаблоны из разделов ниже.

## 5. Где смотреть в Метрике
- **Отчёты → Стандартные → Источники → Метки UTM.**
- Вкладывай группировки: **UTM Campaign → UTM Content** — получишь дерево «статья → конкретный пост».
- ❌ Не ориентируйся на «Источник трафика (детально)» — заходы из приложений без referrer там могут показываться как «Прямые».
- Учитывай **задержку обработки** (до нескольких часов) и правильный **период дат**.

**Быстрый тест за минуту:** открой UTM-ссылку на телефоне → Метрика → **«В реальном времени»** → визит с нужным источником появится за секунды.

## 6. Площадка: Pinterest

### Как Pinterest обходится с метками (проверено)
- При **клике по пину** Pinterest **сам переписывает** `utm_source` → `Pinterest` и
  `utm_medium` → `organic` — что бы мы ни поставили в ссылке.
- `utm_campaign` и `utm_content` он **сохраняет** — они доходят до сайта без изменений.
- Поэтому нормально, что **в редактировании пина ссылка одна, а при клике на сайте — другая**
  (source/medium подменяются на лету).
- Из приложения Pinterest часто теряется referrer → **без меток переход = «прямой»**.

### Что это значит на практике
Тебе достаточно правильно задать `utm_campaign` + `utm_content`. `utm_source=Pinterest` и
`utm_medium=organic` пиши для единообразия (Pinterest всё равно поставит их же).

### Шаблоны ссылок
```
…/razdeliteli-dlya-yashchikov/?utm_source=Pinterest&utm_medium=organic&utm_campaign=razdeliteli&utm_content=ВАРИАНТ
…/kak-navesti-poryadok-v-komode/?utm_source=Pinterest&utm_medium=organic&utm_campaign=komod_poryadok&utm_content=ВАРИАНТ
…/organayzer-dlya-belya-v-komod/?utm_source=Pinterest&utm_medium=organic&utm_campaign=organayzer_belya&utm_content=ВАРИАНТ
```
«Размножаешь» пины одной статьи → меняешь **только** `utm_content` (`action`, `pain`, `before-after`…), `utm_campaign` оставляешь прежним.

### Нюансы Pinterest
- `utm_source` пиши с **большой буквы** (`Pinterest`) — именно так его ставит сам Pinterest;
  если написать `pinterest`, в отчёте может появиться вторая строка.
- **Реклама (Pinterest Ads):** medium будет уже не `organic`. Для платных пинов помечай
  отдельно (например `utm_content=ad`), чтобы не смешивать с органикой.
- **Старые пины без UTM** приземляются как «прямые». Лечится: отредактировать ссылку пина
  (вставить UTM) или пересоздать пин.

*На сайте уже настроено:* обложки статей отдают пину готовую ссылку с UTM
(атрибут `data-pin-url`), и кнопка «Поделиться → Pinterest» тоже добавляет метку.
Но при **ручном** создании пинов вставляй ссылку с UTM сама — по шаблону выше.

## 7. Площадка: ВКонтакте *(черновик — проверить на практике)*
- `utm_source=vk`, `utm_medium=social` (для постов/сообщества), `utm_medium=cpc` (таргет).
- `utm_campaign` = статья, `utm_content` = конкретный пост/креатив.
- ВК **не подменяет** метки сам — задаём всё полностью.
- Шаблон: `…/<slug>/?utm_source=vk&utm_medium=social&utm_campaign=<статья>&utm_content=<пост>`

## 8. Площадка: Telegram *(черновик)*
- `utm_source=telegram`, `utm_medium=social`.
- `utm_campaign` = статья, `utm_content` = пост/канал.
- Метки не подменяются. Учти: при пересылке внутри TG ссылка сохраняется.
- Шаблон: `…/<slug>/?utm_source=telegram&utm_medium=social&utm_campaign=<статья>&utm_content=<пост>`

## 9. Площадка: Instagram / прочее *(черновик)*
- `utm_source=instagram`, `utm_medium=social` (link in bio / stories / reels — различай через `utm_content`).
- Шаблон тот же.

> Площадки 7–9 пока не выверены поведенчески. По каждой при первом запуске
> делаем тест в реальном времени и фиксируем, не подменяет ли площадка метки.

---

## 10. Частые ошибки
- 🚫 Кинули «голый» URL без UTM → переход в «прямых».
- 🚫 Разный регистр источника (`pinterest` / `Pinterest`) → две строки в отчёте.
- 🚫 Вариант пина в `utm_campaign` (`razdeliteli-action`) вместо `utm_content` → статья «размазывается» по десятку кампаний.
- 🚫 Пробелы/кириллица/разные разделители в значениях → грязные отчёты.

## 11. Чек-лист перед публикацией поста/пина
1. ✅ Ссылка на статью **с UTM** (не «голый» URL).
2. ✅ `utm_source` = площадка (для Pinterest — с большой буквы).
3. ✅ `utm_campaign` = статья (из таблицы в п. 3).
4. ✅ `utm_content` = конкретный пост/креатив.
5. ✅ Латиница, нижний регистр, дефис как разделитель.
