# Картинки для @umestno_home_bot

## `bot_example_vertical.jpg`

Образец полного результата для callback-кнопки «Пример результата».
Формат: **вертикальный 2:3** (например 1080×1620 px). Telegram-лента
на телефоне займёт большую высоту экрана — блоки и текст крупные,
читаются без тапа в полный размер.

Что должно быть на картинке (один экран):
- Схема ящика с цветными зонами и подписями (Блок 1 Джинсы, …)
- Памятка «Как сложить» с иконками по типам вещей
- Блок «Почему эта схема подходит» с маркерами
- Карточки рекомендуемых органайзеров с подписями

Это **демо-образец**, не реальный расчёт под конкретного пользователя.
Формулировки в боте подаются честно: «Так выглядит готовая схема. Под
ваш ящик она будет своя».

Если файл не загружен — бот при нажатии на «Пример результата»
отправит текстовое сообщение с ссылкой на сайт вместо картинки.
